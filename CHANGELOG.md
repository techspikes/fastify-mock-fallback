# Changelog

All notable changes to this project will be documented in this file.

## [1.0.2] - 2026-09-22

### Fixed

- Ignore request examples with `externalValue` during request matching.

### Changed

- Support Fastify `^5.0.0`.

## [1.0.1] - 2026-09-21

### Changed

- Restrict test helper specifications to `.json` and `.yaml` file paths.

## [1.0.0] - 2026-09-21

### Changed

- Preserve OpenAPI route definition order when registering mock routes.

## [0.2.1] - 2026-05-31

### Added

- Enhance OpenAPI 3.x specification support.
- Warn when a parameterized operation has no response example.

## [0.1.0] - 2026-05-30

### Added

- Initial release of the Fastify mock fallback plugin.
